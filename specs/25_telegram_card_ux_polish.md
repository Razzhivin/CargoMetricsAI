# Спецификация Итерации №2: Патч №25 — Исправление отображения админ-лимита и форматирование карточки логиста

## 1. Контекст и Проблемы
1. Для `ADMIN_CHAT_ID` в сообщении выводится техническое значение `Integer.MAX_VALUE` (`2147483647`).
2. Блок рекомендаций (`logisticNotes`) выводится сплошным текстом из 10 длинных пунктов, что ухудшает читаемость на экране смартфона.
3. Нейросеть иногда путает «лево/право» при анализе 2–3 фото с разных ракурсов.

## 2. Изменения в кодовой базе

### 2.1. Форматирование лимита (`TelegramNotificationFormatter.java`)
В методе формирования карточки ответа:
* Если `remainingTests == Integer.MAX_VALUE` (режим администратора), выводить:
  `👑 Режим администратора (безлимитный доступ)`
* Для обычных пользователей выводить:
  `🎯 Осталось бесплатных тестов: <remainingTests>`

### 2.2. Читаемое форматирование блока рекомендаций (`TelegramNotificationFormatter.java`)
Перед вставкой `response.logisticNotes()` в HTML-сообщение Telegram добавить перенос строки перед каждым пронумерованным пунктом (`2)`, `3)` и т.д.), чтобы каждый пункт начинался с новой строки:
```java
String formattedNotes = response.logisticNotes()
        .replaceAll("\\s+(\\d+\\))", "\n\$1");
```

### 2.3. Уточнение системного промпта (`CargoAnalysisServiceImpl.java`)
В `SYSTEM_PROMPT` добавить два коротких уточнения для повышения точности и лаконичности:
1. В описание `cargoType` и `logisticNotes`: *«Не используй относительные привязки "слева/справа", так как ракурсы на нескольких фото могут меняться; привязывайся к конструктивным элементам (со стороны мотора, со стороны штурвала, со стороны колес)»*.
2. Ограничить объем `logisticNotes`: *«Сформулируй 4–5 самых важных, конкретных и емких пунктов для водителя (загрязнения, фиксация за раму, хрупкие узлы, защита кузова) без воды и повторов»*.

## 3. Критерии приемки (DoD)
1. В карточке администратора вместо `2147483647` отображается `👑 Режим администратора (безлимитный доступ)`.
2. Каждый пункт рекомендаций начинается с новой строки, а общий объем текста сокращен до 4–5 четких пунктов без путаницы «лево/право».

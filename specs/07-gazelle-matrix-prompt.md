# Спецификация Итерации №1: Патч №7 — Интеграция размерной матрицы автомобилей семейства «Газель» в SYSTEM_PROMPT

## 1. Контекст и Логистическая Бизнес-Логика
Обобщённая рекомендация транспорта в формате `recommended_vehicle: "Малотоннажный фургон"` является избыточно абстрактной для реальных логистических процессов МСБ и индивидуальных перевозчиков.
Для оптимизации распределения заказов и исключения холостых пробегов машин, ИИ должен подбирать транспорт на основе точных коммерческих модификаций кузовов, используемых на рынке (на примере семейства «Газель»).

---

## 2. Архитектурное Решение: Матрица ТС
Внедрить в шаг №4 `SYSTEM_PROMPT` жёсткую классификацию по габаритам кузова:

| Тип ТС | Полезный объём | Габариты кузова (Д х Ш х В) | Оптимальный груз |
| :--- | :--- | :--- | :--- |
| **Газель Стандарт (3м)** | 9 – 12 м³ | 3.0м x 2.0м x 1.8-2.0м | Одиночные высокие предметы (бетономешалка), мелкие переезды. |
| **Газель Удлинённая (4м)**| 16 – 18 м³ | 4.2м x 2.0м x 2.0-2.2м | Неделимые длинномеры, крупные партии коробок, мебель. |
| **Газель Увеличенная (5м)**| 20 – 22 м³ | 5.0м x 2.0м x 2.2-2.3м | Объёмные, но лёгкие каркасные конструкции, утеплитель. |

Если вес груза превышает 1.5 тонны, ИИ обязан автоматически переключаться на среднетоннажный транспорт (ГАЗон Некст / Валдай до 5 тонн), игнорируя объём.

## 3. Изменения в кодовой базе (`org.cargometricsai.service.CargoAnalysisServiceImpl`)

ИИ-агент в IDEA должен обновить строковую константу `SYSTEM_PROMPT`:

```java
    private static final String SYSTEM_PROMPT = """
            Ты — профессиональный ИИ-логист. Твоя задача — проанализировать фото, классифицировать груз, оценить его габариты и РЕАЛИСТИЧНЫЙ ФИЗИЧЕСКИЙ ВЕС, учитывая геометрию и внутренние пустоты.

            Выполняй анализ по шагам:
            1. КЛАССИФИКАЦИЯ: Что на фото? Каков материал (металл, дерево, пластик, текстиль) и тип упаковки.
            2. ОЦЕНКА МАСШТАБА: Найди объект-референс (лист А4, поддон, дверь, колесо, плитка на полу, кирпич) и строго по нему прикинь размеры. Не завышай высоту из-за ракурсов съемки снизу вверх.
            3. ГАБАРИТЫ И ВЕС:
               - Оцени размеры одной единицы груза (Д х Ш х В в метрах).
               - Оцени общий объем всей партии на фото (м³).
               - ОЦЕНКА ВЕСА: Разделяй грузы на МОНОЛИТНЫЕ (сплошные) и ПУСТОТЕЛЫЕ/КАРКАСНЫЕ. 
                 Если перед тобой полая, каркасная или трубчатая конструкция (бетономешалка, пустая бочка, резервуар, собранная мебель), учитывай, что большая часть объёма — воздух. Бытовая бетономешалка весит всего 45-65 кг. Выдавай сухой вес в реалистичном диапазоне (от/до).
            4. ТРАНСПОРТ И МАТРИЦА КУЗОВОВ (Критически важно):
               Подбери конкретный тип автомобиля, исходя из веса, объёма и РАЗМЕРОВ груза (особенно длины и высоты):
               - Вес до 1.5т, Объём 1-12 м³, Длина груза до 3м -> "Газель Стандарт (3м, до 1.5т)"
               - Вес до 1.5т, Объём 13-18 м³, Длина груза 3.1-4.2м -> "Газель Удлинённая (4.2м, до 1.5т)"
               - Вес до 1.5т, Объём 19-22 м³, Длина груза 4.3-5.0м -> "Газель Увеличенная (5м, до 1.5т)"
               - Если груз неделимый, высокий (>1.8м) или имеет торчащие жесткие элементы — ИСКЛЮЧАЙ малые фургоны (Ларгус/каблук).
               - Если общий вес от 1.5т до 5т -> Рекомендуй "Среднетоннажный грузовик (ГАЗон Некст до 5т)".

            Выдай ответ строго в формате JSON без markdown-разметки (без ```json):
            {
              "cargo_type": "тип груза и материал",
              "packaging": "тип упаковки",
              "reference_object_found": "маркер масштаба",
              "single_unit_dimensions_m": {"length": 0.00, "width": 0.00, "height": 0.00},
              "total_estimated_volume_m3": 0.00,
              "estimated_weight_range_kg": "от 00 до 00",
              "recommended_vehicle": "конкретный тип авто из матрицы",
              "logistic_notes": "короткий комментарий по специфике укладки/закрепления груза"
            }
            """;
```

## 4. План повторной валидации (E2E)
1. Обновить константу `SYSTEM_PROMPT` в коде сервиса.
2. Провести повторный E2E-тест.
3. Проверить поле `recommended_vehicle`. Целевой результат для текущих фото бетономешалки: `"Газель Стандарт (3м, до 1.5т)"`.
